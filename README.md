## What you will do

Session 1 starts in QGIS: you see what a GIS does. From session 2 on, every session has two parts on the same data: a **notebook part** on the JupyterHub, where you fetch, clean and analyse geodata with Python (building on pandas and matplotlib from Scientific Programming, 8125), and a **QGIS part** on your laptop, where you look at the result, check it and make maps. Later every dataset also learns to live in a database. You need no GIS background. Topics:

- layers, symbology, maps and layouts (NRW administrative boundaries, DWD stations)
- data types and formats, coordinate reference systems, georeferencing and digitizing your own data
- web services (WMS/WFS) from GDI NRW
- vector and raster analysis, terrain and hillshade
- simple remote sensing: NDVI and supervised classification in QGIS
- Python for geodata: requests, GeoPandas, shapely, rasterio; automation inside QGIS: PyQGIS, Model Designer, batch processing
- geodatabases: ERM, normalization, SQL, PostGIS, OpenHygrisC groundwater data, animated maps
- real-time sensor data on a map

## How a session works (Tuesdays, 180 minutes)

Retrieval quiz, two homework presentations (5 minutes each), short input, guided demo in QGIS or Jupyter that you follow step by step, break, exercise in pairs with a variant task, debrief, exit ticket. If you fall behind during a demo, use the checkpoint projects (`*_checkpoint.qgz`) and catch-up cells in the notebooks.

## Working with this repository

1. **Open the session link in Moodle.** It logs you in to the JupyterHub and puts the repository into your home folder (`~/ee8136-ws2026`). The same kind of link works every week.
2. **Your changes are kept.** If you edit a notebook and I later update it, your version is not overwritten. Copy files before large experiments.
3. **Released files do not change silently.** Corrections come as a new file (`..._fix1.ipynb`) or as an entry in `errata.md`.
4. **QGIS on your laptop.** Keep a course folder on your laptop with the same layout as this repository (download it from GitHub with *Code → Download ZIP*, or single session folders). Large open data that you download yourself (e.g. the NRW boundaries DVG1, see session 1) go **once** into `data/` at the top of that folder; the QGIS projects in the session folders find them there (`../data/`). Small files that belong to one session are in `sNN_date/data/`. Database sessions use the shared PostGIS server.
5. **Data are provided.** Shared data are on the hub (read-only under `/srv/data`).
6. **Solutions** are published after the homework deadline, not in this repository.

### Learning outcomes of the module (module handbook)

After the module you can:

- **LO1**: describe the fundamental concepts of Geographic Information Science and Technology (B1.1)
- **LO2**: have demonstrated proficiency in the basic functions of geospatial software including map creation, map projection and spatial analysis (B2.1, B2.2, B2.3)
- **LO3**: understand the potential of geospatial data related web services (B3.1)
- **LO4**: know the concept of geospatial databases and have gained experience in using relational databases for storing attribute data (B4.1, B4.2)
- **LO5**: are able to create own spatial data and to integrate real-time sensor data (B5.1, B5.2)
- **LO6**: are aware of fundamental remote sensing and related spatial analysis techniques (B6.1)
- **LO7**: can create scripts to automate geospatial data processing (B7.1)
