This repository holds the notebooks, QGIS checkpoint projects and small files for the course. New material appears session by session in the folders `sNN_date` (for example `s01_2026-10-06`). The schedule table at the bottom is updated with every release.

## What you will do

You start by clicking: QGIS shows what a GIS does. Then you learn that every click can be scripted and every dataset can live in a database. You need no GIS background, only the Python basics from Scientific Programming (8125). Topics:

- layers, symbology, maps and layouts (NRW administrative boundaries, DWD stations)
- data types and formats, coordinate reference systems, georeferencing and digitizing your own data
- web services (WMS/WFS) from GDI NRW
- vector and raster analysis, terrain and hillshade
- simple remote sensing: NDVI and supervised classification in QGIS
- scripting: Jupyter on the JupyterHub, PyQGIS, Model Designer, batch processing
- geodatabases: ERM, normalization, SQL, PostGIS, OpenHygrisC groundwater data, animated maps
- real-time sensor data on a map

## How a session works (Tuesdays, 180 minutes)

Retrieval quiz, two homework presentations (5 minutes each), short input, guided demo in QGIS or Jupyter that you follow step by step, break, exercise in pairs with a variant task, debrief, exit ticket. If you fall behind during a demo, use the checkpoint projects (`*_checkpoint.qgz`) and catch-up cells in the notebooks.

## Working with this repository

1. **Open the session link in Moodle.** It logs you in to the JupyterHub and puts the repository into your home folder (`~/ee8136-ws2026`). The same kind of link works every week.
2. **Your changes are kept.** If you edit a notebook and I later update it, your version is not overwritten. Copy files before large experiments.
3. **Released files do not change silently.** Corrections come as a new file (`..._fix1.ipynb`) or as an entry in `errata.md`.
4. **QGIS on your laptop.** Download the files you need from the JupyterLab file browser, or use the QGIS projects in the session folder. Database sessions use the shared PostGIS server.
5. **Data are provided.** Shared data are on the hub (read-only under `/srv/data`).
6. **Solutions** are published after the homework deadline, not in this repository.
